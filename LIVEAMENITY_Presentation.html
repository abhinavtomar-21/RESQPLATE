SLIDE 02 // PROJECT MOTIVATION
Why Did We Choose This Problem?
Everyday Shared Facility Reality
  • Shared facilities are ubiquitous across Housing Societies, Colleges, and Tech Parks.
  • Amenities include Gyms, Swimming Pools, Badminton Courts, Study Rooms & Conference Halls.
  • Facilities exist, but access and usage remain uncoordinated.
  • Users frequently encounter sudden overcrowding or wasted trips.
  • Core Observation: The challenge is NOT just facility availability—it is deciding which facility to use, when to go, and finding better alternatives.
The User Decision Dilemma

SLIDE 03 // EXISTING LANDSCAPE
How Shared Facilities Are Currently Managed
TRADITIONAL SYSTEM WORKFLOW

USER  ➔  LOGIN  ➔  VIEW LISTING  ➔  CHECK STATIC AVAILABILITY  ➔  BOOK SLOT  ➔  VISIT  ➔  USE

What Traditional Systems Know ✅
  • Facility exists in database
  • Static operating hours & slots
  • Basic booking record created
  • User registration details
What Traditional Systems DO NOT Answer ❌
  • Is the facility overcrowded right now?
  • Will it become overcrowded by the time I arrive?
  • Is there a better alternative nearby?
  • What happens if users book but never show up?
SLIDE 04 // GAP ANALYSIS
Where Does The Existing Process Break Down?
👨‍💻 USER BOTTLENECKS
  • Manual Comparison: Users search amenities manually one by one.
  • Static Availability Illusion: Slot shows "Available" even if 50 people are inside.
  • No Crowd Prediction: Zero visibility into future crowd spikes.
  • No-Show Wasted Bookings: Slots locked by missing users.
🏢 ORGANIZATION BOTTLENECKS
  • Peak-Hour Congestion: Severe overcrowding while other facilities sit empty.
  • Uneven Utilization: Gym at 100%, Yoga room at 10%.
  • Unmonitored No-Shows: No mechanism to detect or release ghost bookings.
  • Historical Reporting Only: No active control tools during peak hours.
